# ESP32-S3 N16 status

There is no universal ESP32-S3 N16 board definition. A usable build must match the board's GPIO wiring, USB mode, PSRAM mode, antenna/radio hardware, and bootloader settings.

To start a board-specific profile, add `MARAUDER_S3_N16` to `esp32_marauder/configs.h` and define only the features present on the board. A headless board can use BLE/serial console and PSRAM, but should not claim a display, SD card, GPS, or extra radios unless those parts are physically present. Compile and test on the exact board before publishing a binary.

The existing upstream `MARAUDER_MULTIBOARD_S3` profile targets the Flipper Zero Multi Board S3 and is not a generic replacement for an ATewin or other ESP32-S3 N16 board.
